Install Rewind

Rewind is a community rebuild of Powder: faster, lighter, with custom game support. Setup downloads everything it needs, including the parts of Powder it still uses, so you don't need Powder installed.

Install location

Setup will

  • download Powder's recorder, AI and game files
  • download ONNX Runtime and DirectML from Microsoft, plus PaddleOCR text models, for Add Custom Game (about 50 MB)
  • add Rewind to the Start menu, the desktop and Apps & features (to uninstall it)
