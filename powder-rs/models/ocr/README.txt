PaddleOCR PP-OCRv4 text detector (det.onnx) + recogniser (rec.onnx) with its character list (dict.txt).
Source: PaddlePaddle/PaddleOCR (Apache-2.0), ONNX export as distributed by RapidOCR (Apache-2.0).
You can swap in other PP-OCR ONNX models (e.g. an English-only rec model) - keep the file names or pass --ocr-models.
